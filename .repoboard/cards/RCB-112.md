Shape (the builder writes the brief; the owner's felt experience decides the mechanics, D-2026-09-01): a page per served repo (the repo the URL shows, like Flow) with three bands — (1) HEALTH: the last gate result per check (vitest files/tests, typecheck, lint, build) with its timestamp and sha, read from a recorded gate line (a seat's log block or a small ledger the gate script writes; never re-run from the page; null / 'no gate recorded' when none); (2) COMMITS: the last N commits on origin/main and the working branch (sha, subject, author-as-seat, age), commits-per-day over the last 14 days, derived live from git like backlinks (0 B added to the board); (3) SYSTEMS + COVERAGE: the RCB-110 A line per system (tests: N files) and the systems.yml summary, or the RCB-111 empty state. Provenance on every number (which file / which git command). Measured: page bytes and time-to-first-paint on both dogfood repos.

Order: after RCB-109, RCB-111 and RCB-110 A. RCB-110 B (coverage-report source) is a follow-up card the builder files when A lands.

Control: a temp repo with no .git and no .repoboard/ renders every band as its null state and no error. Stop-and-ask: none expected (read-only over git and board files).
