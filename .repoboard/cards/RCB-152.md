## Evidence

RCB-142's measurement (README §Status, 2026-09-24): installing `repoboard` resolves 98 production
transitive packages for `packages/server` (`pnpm-lock.yaml`); 93 exist only because of the SDK's
HTTP/OAuth transport (express, hono, ajv, jose, eventsource and their deps), about 23.8 MB of
`node_modules/.pnpm` (the SDK package itself 5.9 MB). The seat's spot-check of the non-SDK closure:
chokidar, readdirp, ws, yaml, zod. `mcp.ts` imports only `McpServer` and `StdioServerTransport`.

## Do

1. Brief first: list every MCP method `mcp.ts` answers today (initialize, tools/list, tools/call,
   and whatever else the SDK answers on our behalf, e.g. ping, notifications/initialized) — measured
   from a recorded stdio session against the current build, not from the spec.
2. Implement newline-delimited JSON-RPC 2.0 over stdin/stdout for exactly that set; tool input
   schemas stay zod (already a direct dependency).
3. DoD: the recorded session replays byte-for-byte equivalent (modulo ids and timestamps); the
   server's prod transitive count is re-measured from the lockfile and the README §Status sentence
   is rewritten with the new number; the SDK is removed from `packages/server/package.json`.
