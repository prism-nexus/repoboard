## Locked decisions (the orchestrator's; do not re-open — build them, and CORRECT the brief in your §7 if a measurement contradicts one)

1. **File:** `.repoboard/decisions.jsonl`, one JSON object per line, UTF-8, `\n`-terminated, **append-only**.
   Core exposes NO update or delete for a decision. A reversal or an answer is a new line.
2. **Shape:** `{ "id": "D-<n>", "ts": ISO-UTC-seconds, "item": string, "words": string, "heardBy": string,
   "refs"?: string[], "open"?: true, "letters"?: string[], "resolves"?: "D-<n>" }`. **`id` is the FIRST
   key** on every line (see 6). `words` is the owner's text verbatim — never trimmed beyond outer
   whitespace, never reflowed. `heardBy` is the seat/actor that heard it (`--by`, default
   `$REPOBOARD_ACTOR`, then `$USER`, then `cli`/`mcp`/`web`).
3. **Ids:** `D-<n>`, `n` = max existing + 1 (scan the file; D3's rule, no counter).
4. **Open letter:** `open: true` + `letters: ["A1 …", "A2 …"]`, `words` may be empty for an ask. It is
   **resolved** when a later line carries `resolves: "D-<n>"`. "Open decisions" = open lines with no
   resolver. Resolving a non-existent or already-resolved id is a `{ok:false, error}` naming it.
5. **Core (pure, `packages/core/src/decisions.ts`):** `DecisionSchema` (zod, matching the card schema
   style), `parseDecisionLine(line) → {ok,decision}|{ok:false,error,line}`, `parseDecisions(text) →
   {decisions, invalid[]}` (a bad line is reported, the rest still parse — like invalid cards),
   `formatDecision(d) → string` (one line, `id` first, no trailing newline), `allocateDecisionId(existing)`,
   `createDecision(input, {now, actor}) → {ok, decision}|{ok:false,error}` with the resolves check
   taking the existing list, `openDecisions(list)`. Export from `index.ts`. The purity test must still pass.
6. **Refs:** `decisions.jsonl@D-7` must resolve. `refs.ts`'s `@token` rule matches a line that STARTS
   with the token; a JSONL line starts with `{`. Add ONE rule to `resolveRef`: when the file ends in
   `.jsonl`, `@token` matches the first line whose parsed JSON `id` equals the token (exact), span = that
   one line. Document it in the AGENTS.md refs table. Nothing else in refs changes.
7. **Server:** the store watches `decisions.jsonl` like it watches cards (re-read on change, never
   trust memory — D6). `CardStore` gains `decisions(): Decision[]`, `decide(input, actor)`,
   `ask(input, actor)`; the events log gets `type: 'decision'` lines (`cardId` → use the decision id in
   `cardId`? NO — widen `Event` with an optional `decisionId` and let `cardId` be `''` for decision
   events; the ticker renders "D-7 decided by <actor>"). Map-only roots refuse both writes (K10's shape).
8. **CLI:** `repoboard decide "<item>" --words "<verbatim>" [--by <seat>] [--ref r]... [--resolves D-n]`
   prints `decided D-8 <item>`; `repoboard ask "<item>" --letter "A1 …" [--letter …]... [--ref r]... [--by]`
   prints `asked D-9 <item> (2 letters)`; `repoboard decisions [--open] [--json]` prints a table
   (`ID  WHEN  BY  ITEM  WORDS(60)`), `--json` one compact object per line. Exit codes as AGENTS.md §2.
9. **MCP:** `record_decision`, `ask_owner`, `list_decisions` (`open?: boolean`, `full?: boolean`) — the

10. **HTTP:** `GET /api/decisions` (`?open=1`), `POST /api/decisions` (`{item, words, heardBy, refs?,
