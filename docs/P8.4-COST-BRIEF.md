## Locked decisions (build them; CORRECT in §7 with the measurement if one is wrong)

1. **What "cold context" means, exactly (and print the definition in `--help`):** the sum of bytes of
   (a) `CLAUDE.md` at the repo root if present (and `.claude/CLAUDE.md`, `CLAUDE.local.md` if present —
   each listed separately); (b) `AGENTS.md` at root and `docs/AGENTS.md` if present; (c) **every
   repo-relative path named in backticks in (a)** that exists as a file — first-order links only, no
   recursion, no globs, deduplicated, `..` and absolute paths ignored; (d) the NAMES (not sizes) of MCP
   servers in `.mcp.json` at root, with a fixed note "schema bytes are per-harness; repoboard's own is
   measured in AGENTS.md". Tokens ≈ bytes / 4, printed as `≈N tok`, and labelled an estimate.
2. **Output:** a table `FILE  BYTES  ≈TOK  WHY` (why = `root`, `linked from CLAUDE.md`, `agents`) then
   `total  <bytes>  ≈<tok>`, then `CLAUDE.md <bytes> of budget <budget>  OK|OVER`. `--json` one object.
   **Exit 1 when `CLAUDE.md` exceeds `--budget`** (default **8192**), exit 0 otherwise; the budget is
   also readable from `board.yml` as `claudeMdBudgetBytes:` (CLI flag wins). Missing CLAUDE.md → the
   line says `CLAUDE.md — absent` and cannot be OVER.
3. **Core (pure, `packages/core/src/cost.ts`):** `extractLinkedPaths(claudeMdText) → string[]` (the
   backtick rule, tested against fpj's real CLAUDE.md copied into a fixture), `summarizeCost(entries,
   budget) → CostReport`, `formatCostTable(report)`. The server does the I/O (`stat` and `readFile`),
   the core does the arithmetic and the rule. Purity green.
4. **Wire it into P8.3's `check`:** `costFinding()` returns `cost-over-budget CLAUDE.md <bytes> >
   <budget>` when over; `check` exits 1 for it (not warning-grade — this is the failure nobody notices).
5. **MCP `cost`** (`budget?: number`) → same JSON. **HTTP `GET /api/cost`.** **Web:** one tile on the Map
   view header: `cold context ≈10.2k tok · CLAUDE.md 5.0 KB ✓` (✗ in warning color when over); click →
   the table in the Drawer.
6. **Measure repoboard itself and freshpickedjobs** (read-only on fpj: run `cost` with `--root
   /Users/hometown/Projects/Repos/freshpickedjobs`, which reads files and writes NOTHING — prove with
   `git -C … status --short` before and after, identical) and put both tables in `docs/AGENTS.md` §11
   "Cost" and your §7. The fpj number is the first real measurement of the thing this task exists for.
